# Published numerical evidence

This is a compact snapshot of actual retained CalculiX results, not a new solve. The exported JSON records and inputs are copied unchanged; source file hashes are in `export-manifest.json`.

Open [report.html](report.html), [comparison.json](comparison.json), [backend qualification](backend-qualification.json), or [unit equivalence](unit-equivalence.json). Download the HTML to view its embedded plots.

Raw STEP, mesh, deck, DAT/FRD, logs and per-run source snapshots are not bundled in Git. Reproduce them with the commands in [the installation guide](../installation.md). The result records retain the original raw-artifact checksums.

Numerical passing is limited to the declared scope. Design status remains unassessed, and raw global clamp peaks are not qualified as converged design stresses.
